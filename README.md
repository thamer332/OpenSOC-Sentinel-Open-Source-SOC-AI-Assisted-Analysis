# OpenSOC Sentinel — AI-Assisted SOC Lab

An educational Security Operations Center (SOC) lab built with virtual machines, combining security monitoring, attack detection, network analysis, and assisted alert reporting.

## Project Overview

This project demonstrates a virtualized SOC environment designed for defensive security testing and alert investigation.

## Components

- **Wazuh SIEM** — Security event collection and alert monitoring.
- **pfSense** — Network firewall and traffic control.
- **DVWA** — Controlled web application security testing.
- **Kali Linux** — Authorized security testing.
- **Wireshark** — Network traffic analysis.
- **Shuffle** — SOAR workflow exploration.
- **AI SOC Analyst** — Flask-based alert analysis interface with PDF reporting and local fallback.

## Scope and Limitations

This is an educational lab running in a virtualized environment. Results reflect the tests performed and documented in the report. Automated response and AI-generated analysis should not be assumed to work unless explicitly demonstrated.
